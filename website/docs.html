AgriSignal Documentation

Everything needed to run offline crop advisories, IPM checks, and LWW-Element-Set sync hubs locally or in field deployments.

1. Installation

git clone https://github.com/codesphere-u/agrisignal.git
cd agrisignal
uv sync --all-extras

2. CLI Commands

agrisignal advise --crop maize --zone lake_victoria_crescent --lang lg
agrisignal pest-risk --crop robusta_coffee --temp 26 --humidity 84 --rain 140
agrisignal simulate-sync
agrisignal serve --host 127.0.0.1 --port 8080

3. CRDT Sync Protocol

CentralSyncHub validates SHA-256 payload hashes, deduplicates retries idempotently, and orders conflicting plot mutations using (lamport, wall_time_ms, node_id) Hybrid Logical Clock tuples.

4. EN / LG / SW Multilingual SMS

agrisignal.i18n.translator renders English (en), Luganda (lg), and Swahili (sw) summaries strictly capped at ≤160 characters for rural GSM-7 handsets.

5. FastAPI Workbench

Start the low-bandwidth HTTP API and field workbench via agrisignal serve, exposing advisory, pest-risk, sync simulation, and health endpoints.
